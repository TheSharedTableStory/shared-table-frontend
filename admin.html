Pricing & Policies

Verification Fee Policy

Experience Approval Threshold

Free events (A$0) always go to the moderation queue. Paid events priced below this threshold also queue for review. Paid events priced at or above this threshold publish straight to Explore.

Host Settlement & Recovery

Money policy for host payouts and cancellations. Payout hold is how long a host's earnings are held after an event before release (it also governs shortfall and cancellation settlement timing). Host-cancel recovery is the anti-abuse penalty charged when a host cancels. Shortfall processing fee is retained when refunding unused-seat pre-funding. Stuck-debt collection window is how long a payout-deduction debt sits with no held payout to collect it from before the platform tries to charge the host's saved card directly.

Check email delivery

Send yourself a test email to check that our emails are going out. Useful when a host says they never received a confirmation.

Per-Currency Platform Fees

The platform fee is the greater of (tier % × booking value) and the tier's local minimum, set per currency. It is host-absorbed (deducted from the host payout). Minimums are in each currency's own units and are never FX-converted. Hosts can only list in enabled currencies. AUD ships with the production values as the default. Edit any currency freely.

Bands for AUD, values in major units (e.g. 50 = $50). Start at 0, contiguous, last band open-ended (leave Max blank). % as a percentage (e.g. 10 = 10%). Min is the local floor.
